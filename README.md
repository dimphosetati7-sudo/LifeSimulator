LifeSimulator

LifeSimulator is a Java console game where players make choices and experience different parts of virtual life.
Features

- Create your own character
- Choose a career and earn money
- Get promotions and improve your career level
- Build friendships and romantic relationships
- Experience breakups, enemies, rivals and drama
- Rent or buy properties
- Buy cars and luxury items
- Host parties and improve your reputation
- Experience random events and unexpected expenses
- Complete a 30-day survival challenge
- Save and load your game

Technologies

- Java
- NetBeans IDE

How to Run

1. Download or clone this repository.
2. Open the project in NetBeans.
3. Run the `LifeSimulator.java` file.
4. Follow the menu instructions.

Project Status

This project is a work in progress. More features and improvements may be added as development continues.
